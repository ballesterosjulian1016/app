# Garaje

Web/PWA de compra-venta de coches. Sin dependencias: solo HTML, CSS y JavaScript.

## Probarlo en Codespaces
    python3 -m http.server 8000
Abre el puerto 8000 que te ofrece Codespaces. Para publicarlo gratis: GitHub Pages, Vercel o Netlify.

## Estructura
- index.html: pantalla y formularios
- style.css: diseño
- app.js: listado, filtros, ficha, publicar y eliminar coches (se guardan en el navegador)
- manifest.json y sw.js: lo que la hace instalable en el móvil
